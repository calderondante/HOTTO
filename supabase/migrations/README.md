# Migraciones

No hay migraciones de producto en este bootstrap. Crear las primeras después
de validar entidades, catálogo curricular y reglas de publicación. Cada tabla
expuesta deberá tener RLS y políticas de acceso explícitas, con pruebas de
lectura pública y de escritura administrativa. No generar semillas académicas
ni PDFs ficticios para llenar la biblioteca.
